## Intended behavior and invariants

- Preserve the published `@gethookmyapp/cli` command, supported Node engine range, source/runtime API, and existing npm package lifecycle.
- Keep dependency resolution reproducible from npm's existing `package-lock.json`; update compatible package lines and only cross a major boundary when the published patched advisory requires it and tests confirm compatibility.
- Pin local/CI Node 24 use to the authorized patched runtime `24.22.1`; use a repo-local/process-local runtime during remediation and verification without changing shared Node installations or shell profiles.
- Do not publish, deploy, provision resources, change schemas, or alter secrets.
